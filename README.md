# AI Recipe Recommendation Chatbot 🍲🤖

An interactive chatbot application that suggests personalized recipes based on available ingredients using Kaggle datasets and a Gradio web interface.

---

## 📌 Project Overview
The *Recipe Recommendation Chatbot* is designed to help users figure out what to cook using the ingredients they already have at home. By processing Kaggle recipe datasets, the chatbot intelligently matches ingredients and suggests delicious dishes through a user-friendly web interface.

---

## ✨ Key Features
•⁠  ⁠*Ingredient-Based Recommendations:* Suggests recipes based on user-provided ingredients.
•⁠  ⁠*Kaggle Dataset Integration:* Powered by comprehensive food and recipe datasets.
•⁠  ⁠*Interactive UI:* Built with Gradio for a seamless and responsive conversational experience.

---

## 🛠️ Tech Stack & Tools
•⁠  ⁠*Programming Language:* Python
•⁠  ⁠*Data Processing:* Pandas, NumPy
•⁠  ⁠*Machine Learning / NLP:* Data preprocessing and matching algorithms
•⁠  ⁠*Web Interface:* Gradio
•⁠  ⁠*Data Source:* Kaggle Datasets
